## Project Description

This project was created for Assignment 5: JavaScript Basics (DOM Manipulation & Events).

The website contains several pages with different JavaScript tasks. Each page can be opened using the navigation bar.

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Tasks

### Task 0: First Script
- Display an alert message
- Print student name and group in the console

### Task 1: Variables and Operators
- Use string, number and boolean variables
- Perform arithmetic operations
- Combine strings

### Task 2: Changing Content
- Change paragraph text by clicking a button

### Task 3: Changing Styles
- Change the background color of a block
- Change the font size

### Task 4: Creating and Removing Elements
- Add items to a list
- Remove items from a list

### Task 5: Mouse Events
- Change box color on mouseover
- Restore the color on mouseout

### Task 6: Keyboard Events
- Display input text using the keyup event

### Task 7: Calculator
- Addition
- Subtraction
- Multiplication
- Division

### Task 8: To-Do List
- Add tasks
- Mark tasks as completed
- Delete tasks
- Store tasks in a JavaScript array

## How to Run

1. Download or clone the repository.
2. Open the project folder in VS Code.
3. Open index.html in a browser or use Live Server.
4. Use the navigation bar to switch between pages.
